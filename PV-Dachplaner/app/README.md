# PV-Dachplaner – App

Svelte + Vite + TypeScript. Rechenkern: [`../packages/geometry-core`](../packages/geometry-core).

```bash
npm install
npm run dev        # Entwicklung
npm run check      # Typprüfung (svelte-check)
npm test           # Unit-Tests
npm run build      # Ausgabe in dist/
npm run preview &  # gebaute App unter http://127.0.0.1:4173
npm run e2e        # Browser-Rauchtest gegen die laufende Vorschau
```
